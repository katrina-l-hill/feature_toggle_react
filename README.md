# Creating a Feature Toggle Component

This project demonstrates a simple **Feature Toggle** implementation in a React Native app using Expo. It conditionally renders features based on props passed to a reusable component.

## Features
- Reusable Toggle Component
- Conditional Rendering
- Clean and Readable JSX

## Installation
- Clone the repo:
  - git clone `https://github.com/katrina-l-hill/feature_toggle_react`
  - cd feature-toggle-expo
  - npx expo start
